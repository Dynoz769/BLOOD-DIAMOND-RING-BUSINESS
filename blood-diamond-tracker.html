    Discord reminder – pending members

    To really ping a role, use <@&RoleID> (right-click the role → Copy Role ID). Each member's own Discord name can be set via Edit → Discord name.

    Optional: send automatically via webhook

    Server Settings → Integrations → Webhooks → New Webhook → pick the channel → Copy Webhook URL.

    Discord IDs

    Discord → Settings → Advanced → turn on Developer Mode. Then right-click a member → Copy User ID and paste it here. With an ID the message uses <@ID>, which becomes a real tag when you send it.

    Weekly quotas (pcs)

    Start next week?

    • This week is saved to history (read-only).
    • Daily submissions reset to 0.
    • Adv Submission (extra above the requirement) is automatically deducted from next week's quota, and any leftover keeps rolling to the following weeks.
    • Any shortfall becomes Due Submission (not for KIV, Leave or exempt members).
